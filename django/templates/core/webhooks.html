Vérifier les événements dans votre outil

Le corps JSON contient id, type, created_at, company_uid et data. L'en-tête X-ZeFacture-Signature contient t=horodatage,v1=signature. Calculez HMAC-SHA256 sur l'horodatage, un point, puis le corps HTTP brut, avec le secret fourni. Comparez les signatures en temps constant, refusez un horodatage trop ancien et dédoublonnez sur id. Répondez avec un statut 2xx ; les redirections ne sont pas suivies.
