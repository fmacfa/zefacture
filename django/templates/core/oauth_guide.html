INSTALLATION AUTO-HÉBERGÉE

Configurer Google et Microsoft

Une application par fournisseur pour votre instance, puis une autorisation distincte par entreprise cliente.

Connexion email
Ces connexions servent à envoyer les emails de votre entreprise. Elles ne remplacent pas la connexion à ZeFacture et ne donnent pas accès à votre boîte de réception. Un compte Gmail ou Microsoft est nécessaire pour créer les applications.

Google : Gmail et Workspace

  1. Ouvrez la console Google Cloud avec votre compte Google. Créez un projet réservé à votre instance.
  2. Dans la bibliothèque des API, activez Gmail API.
  3. Dans Google Auth Platform, renseignez Branding (nom, email de support, domaine, accueil et politique de confidentialité), Audience (External pour des comptes de plusieurs entreprises) et vos utilisateurs de test.
  4. Dans Data Access, ajoutez les permissions ci-dessous. L’envoi Gmail est une permission sensible : préparez la vérification Google avant une ouverture à vos clients.
  5. Dans Clients, créez un client OAuth Application Web et copiez exactement l’adresse de retour ci-dessous. Aucun flux JavaScript ni accès complet à la messagerie n’est nécessaire.
  6. Conservez le Client ID et le secret dans la configuration privée du serveur (GOOGLE_MAIL_CLIENT_ID et GOOGLE_MAIL_CLIENT_SECRET). Chaque entreprise peut ensuite choisir Gmail et cliquer Se connecter avec Google. Une application propre à l’entreprise peut aussi être renseignée dans les paramètres avancés.

En mode Testing, les comptes autorisés doivent être ajoutés comme testeurs et les autorisations durables concernées expirent après sept jours. Une application interne Workspace est réservée à son organisation.

Microsoft : Outlook et Microsoft 365

  1. Ouvrez le centre Microsoft Entra. Créez ou rejoignez un annuaire disposant du droit d’inscrire des applications. Selon votre compte, l’accès à un annuaire peut demander une offre Microsoft adaptée.
  2. Dans App registrations → New registration, inscrivez ZeFacture. Pour accepter Outlook.com et Microsoft 365, choisissez comptes de tous les annuaires et comptes Microsoft personnels.
  3. Ajoutez une plateforme Web et l’adresse de retour exacte ci-dessous. Laissez les flux implicites et public client désactivés.
  4. Dans API permissions, utilisez uniquement les permissions déléguées Microsoft Graph User.Read et Mail.Send, avec identité et offline_access. N’ajoutez pas de permission applicative ni Mail.ReadWrite. Une organisation peut demander le consentement de son administrateur.
  5. Dans Certificates & secrets, créez un secret d’application. Copiez sa valeur, et notez sa date d’expiration. L’identifiant du secret n’est pas sa valeur.
  6. Enregistrez l’Application (client) ID et le secret dans MICROSOFT_MAIL_CLIENT_ID et MICROSOFT_MAIL_CLIENT_SECRET, puis connectez le compte depuis cette interface.
{{ microsoft_scope }}

La connexion accepte l’identité du compte autorisé. Les boîtes partagées et l’envoi en tant qu’alias ne sont pas configurés par ce parcours. Anticipez le renouvellement du secret avant son expiration.

Avant de connecter vos clients

Pour zefacture.com, préparez le domaine, le DNS et le serveur HTTPS avant de créer les clients OAuth de production. Utilisez une application de développement distincte pour les essais locaux. Les adresses ci-dessus reflètent APP_URL de l’instance courante.

Déclarez les pages réelles de votre instance : accueil, confidentialité, conditions et contact. L’exploitant doit renseigner son identité, ses coordonnées et sa politique de conservation avant publication.

Après autorisation, utilisez Vérifier la connexion sans envoyer, puis déclenchez vous-même un email de test et contrôlez sa réception. Le guide complet GUIDE_AUTOHEBERGEMENT.md dans les sources détaille l’installation, la vérification fournisseur, la personnalisation et la maintenance.

La déconnexion efface les jetons locaux. Pour retirer aussi le consentement, ouvrez les applications autorisées de votre compte Google ou Microsoft ; la révocation d’une application partagée peut affecter d’autres connexions utilisant ce compte.
